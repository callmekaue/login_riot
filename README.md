# 🎮 Riot Games Login Clone

Uma recriação da tela de login da Riot Games desenvolvida com HTML, CSS e JavaScript, focada em fidelidade visual, responsividade e boas práticas de desenvolvimento Front-End.

## 🚀 Demonstração

O projeto reproduz a experiência visual da página de login da Riot Games, incluindo:

- Interface moderna e responsiva
- Layout inspirado no cliente oficial da Riot Games
- Campos de autenticação estilizados
- Design adaptável para desktop e dispositivos móveis
- Animações e efeitos visuais

## ⚙️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/callmekaue/login_riot.git
```

2. Acesse a pasta do projeto:

```bash
cd login_riot
```

3. Abra o arquivo `index.html` em qualquer navegador.

Ou utilize a extensão **Live Server** do Visual Studio Code.
